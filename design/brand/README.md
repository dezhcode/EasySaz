# نشان ایزی‌ساز — «سِ رو به بالا»

حرف «س» از «ساز» با سه دندانه که پله‌پله بالا می‌روند: ساختن مینی‌اپ، قدم‌به‌قدم.
یک وزن خط، سرهای کاملاً گرد (دوستانه و ساده). طراحی‌شده با اسکیل logo-design
(بررسی SVG، آزمون ۱۶ پیکسل، تک‌رنگ، معکوس و آزمون قفسه کنار نشان‌های دیگر).

## فایل‌ها

| فایل | کجا |
|---|---|
| `easysaz-symbol-color.svg` | نشان اصلی، بنفش، از ۴۸ پیکسل به بالا |
| `easysaz-symbol-small.svg` | برش کوچک (خط ضخیم‌تر، فاصله‌های بازتر) برای ۱۶ تا ۴۰ پیکسل: favicon، نشان «ساخته شده با ایزی‌ساز» |
| `easysaz-symbol-black.svg` / `-white.svg` | تک‌رنگ؛ سفید فقط روی زمینهٔ تیره یا بنفش |
| `easysaz-horizontal-*.svg` | نشان + «ایزی‌ساز»؛ نشان سمت راست (اول خوانده می‌شود) |
| `easysaz-stacked-color.svg` | نشان بالا، اسم پایین |
| `easysaz-app-icon.svg` / `-1024.png` | آیکون اپ: نشان سفید روی کاشی بنفش |
| `easysaz-bot-avatar-640.png` | عکس پروفایل @EasySazBot (در BotFather با `/setuserpic`)؛ برای برش دایره‌ای تلگرام امن است |
| `board-in-use.png` | نمونهٔ استفاده روی آیکون، سایت، پروفایل، کارت ویزیت |

favicon و آیکون‌های وب پنل در `app/webapp/static/brand/` است.

## رنگ

| نام | HEX | RGB |
|---|---|---|
| بنفش ایزی‌ساز | `#4B2EE8` | 75, 46, 232 |
| جوهر (اسم) | `#17142B` | 23, 20, 43 |
| سفید | `#FFFFFF` | |

بنفش روی سفید و سفید روی بنفش کنتراست کافی دارند. **بنفش روی مشکی نه**: روی زمینهٔ تیره نسخهٔ سفید.

## قاعده‌ها

- **فضای خالی دور نشان:** دست‌کم به اندازهٔ ضخامت خط نشان (یک «دندانه») از هر طرف.
- **کمترین اندازه:** نشان اصلی ۴۸ پیکسل؛ زیر آن برش کوچک. نسخهٔ افقی دست‌کم ۱۲۰ پیکسل پهنا.
- **نکن:** کشیدن یا فشردن، چرخاندن، سایه و گرادیان، عوض کردن ترتیب دندانه‌ها،
  گذاشتن نسخهٔ بنفش روی عکس شلوغ یا زمینهٔ تیره، تایپ دوبارهٔ اسم با فونت دیگر.

## یادداشت‌ها

- اسم «ایزی‌ساز» از فونت پیدا (وزن ۸۰۰) به مسیر تبدیل شده؛ مجوز فونت باید استفاده در نشان را پوشش دهد.
- ثبت علامت تجاری را این طرح تضمین نمی‌کند؛ پیش از ثبت، جست‌وجوی حرفه‌ای لازم است.
